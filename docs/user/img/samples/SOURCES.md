# Sample photos

Back to: [User guide](../../README.md)

The screenshots in the README and the user guide show the real program. Only
the scanner input is simulated: these four photos were placed on an image of
a scanner lid by `tools/screenshots.py`, as prints with borders and slight
skew. All four are free of copyright restrictions; they come from the sample
data of [scikit-image](https://scikit-image.org/docs/stable/api/skimage.data.html).

| File | scikit-image name | Photographer / origin | Licence |
|---|---|---|---|
| `cat.jpg` | `chelsea` | Stefan van der Walt | CC0 |
| `coffee.jpg` | `coffee` | Rachel Michetti, courtesy of Pikolo Espresso Bar | CC0 |
| `rocket.jpg` | `rocket` | SpaceX | public domain |
| `hubble.jpg` | `hubble_deep_field` (cropped to 3:2) | NASA | public domain |

The files were converted to JPEG (quality 90); `hubble.jpg` is a crop.
